# Результаты последовательного переноса боевых типов

47 включённых типов реализованы и проверены отдельными CUDA-тестами. После каждого этапа выполнено новое обучение PPO с нуля на 20 000 000 переходов: **940 млн переходов в 47 основных запусках**, без учёта дополнительных замеров и оптимизационных повторов. Seed 42, 250 сред, rollout 100, 4 эпохи, 10 минибатчей, сеть 128×128 tanh.

Веса каждого запуска изменились; сохранение и обратная загрузка checkpoint проверены. Во всех финальных оценках полных побед на карте: **0/1024 argmax и 0/1024 sampled**. Успешные бои не означают прохождения всей карты.

W&B записан локально в offline-режиме: первоначальная попытка облачной записи вернула HTTP 403. Облачных ссылок на графики нет. Артефакты и точные результаты каждого этапа указаны в [машиночитаемом плане](unit-action-stages.json); общая проверка — `results/unit-actions-20261009/training-audit.json`. Последний последовательный этап: `results/unit-actions-20261009/52-aleman-20m/`.

[Графики этапа Aleman на 20 млн](images/reference-actions-20m.png) построены по 20 сводкам, каждая охватывает 1 млн переходов. Средняя скорость learner — 180 018 переходов/с, время 20 млн — 111,1 секунды без компиляции и оценки. Это примерно на 32% медленнее этапа Witch (264 466 переходов/с, 75,6 секунды); промежуточные замеры приведены ниже. За этот этап зарегистрировано 61 164 победы в отдельных боях.

Итоговая проверка: **297 тестов на CUDA**, 590.8 с реального времени, включая запуск WSL, фикстуры и компиляцию. Две группы запускаются штатным scripts/test_gpu.py; кэш JAX новый для этого прогона. Повторные компиляции сокращены общими неизменяемыми фикстурами; проверки jit/vmap сохранены. Ruff и проверка синтаксиса JavaScript проходят. [Свидетельство проверки](validation/reference-unit-actions.json). Контрольные суммы 19 файлов среды/обучения и checkpoint совпадают с запуском Aleman на 20 млн.

## Отдельное обучение на 100 млн переходов

После завершения всех типов выполнено обучение с нуля на текущей карте v71: **100 000 000 переходов**, прежние параметры PPO и seed 42. Веса обновлены, сохранение и обратная загрузка проверены. Контрольные суммы 19 файлов среды и обучения совпадают с этим запуском.

- Средняя скорость learner: **174 675 переходов/с**; синхронизированное обучение — **572,49 с** без компиляции, оценки и сохранения.
- Побед в отдельных боях за обучение: **515 822**; полных побед во время обучения — **0**.
- Итоговая оценка argmax: **0/1024** полных побед, средняя награда **58,58**, длина эпизода **2428,25**.
- Итоговая оценка с выборкой: **0/1024** полных побед, средняя награда **55,71**, длина эпизода **1920,40**.
- W&B записан локально: попытка облачного запуска завершилась HTTP 403 до инициализации learner. Сводки графиков агрегированы по 1 млн переходов из полного metrics.csv с взвешиванием по числу завершённых эпизодов.
