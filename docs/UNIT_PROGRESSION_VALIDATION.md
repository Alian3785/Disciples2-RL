Полный GPU-набор: **267 тестов прошли**, 505,80 с pytest,
513,88 с вместе с подготовкой (8:34, меньше 10 минут).

за 83,72 с вместе с подготовкой; после сокращения состояния — 14 тестов
прогрессии за 43,16 с pytest. Две усиленные проверки позднего прироста
характеристик и брони также прошли (20,03 с с подготовкой).
В последнем статическом прогоне Ruff ошибок нет.

Проверены доли XP и округление, погибшие и отступившие, учёт новых смертей,
порог без здания, одно повышение за бой, сброс лишнего опыта, полное лечение,
все доступные цепочки Легионов, новые характеристики и защиты, числовые
уровни конечных форм, регенерация, повторные бои, сброс, API и блокировки
неподдерживаемых веток. CPU-прогонов нет.

GTX 1660 Ti; JAX 0.11.2, CUDA runtime 13.4.92. Каждый запуск — 5 млн
переходов, 250 сред, rollout 100, 4 эпохи PPO, 10 минибатчей, сети 128×128.
Измерена сумма синхронизированных вызовов learner: среда, выбор действий,
обновления PPO. Компиляция, оценка, логирование и сохранение отдельно.
Во время замеров сервер визуализации остановлен. Настройки PPO не менялись.

- Неизменяемые ID форм противников перенесены из состояния в данные
  сценария: на каждом шаге сохраняются только их уровень и опыт.

этот конкретный компромисс 8 октября 2026 года: «Принять снижение скорости»

реализации не требуется; это не разрешение на дальнейшее замедление.
