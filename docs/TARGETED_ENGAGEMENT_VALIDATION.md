# Проверка направленной атаки на карте

8 октября 2026. База aa0a9ec, карта v21; результат — карта v22.
[Механика и первичные источники](TARGETED_ENGAGEMENT.md).

## Корректность

Новые CUDA-проверки охватывают все 8 направлений с 7 остатками очков
(0/1/2/9/10/11/20), проход рядом, отдых/зелье рядом, несколько соседних
целей, точный состав выбранного врага, отсутствие перемещения/исследования
при атаке, сохранение позиции после победы и отступления, отдельный вход
на очищенную клетку и сервер ручной игры.

Первый целевой прогон: 14 passed, одна проверка выявила обновление битов
посещённости без перемещения. Исправлено: биты меняются только при движении.
Повтор всех 5 новых проверок прошёл за 30,35 с pytest (36,08 с со стартом).
Два полных маршрута и тесты стратегических ходов прошли в целевом прогоне.

Первый полный прогон занял 602,23 с (295 passed, одно устаревшее ожидание
автоматического контакта). Ожидание исправлено; повтор прошёл. Для соблюдения
лимита 10 минут две медленные сверки с независимым эталоном перенесены
в JAX scan с единственной выгрузкой всей последовательности. Все 2048+1024
действия, промежуточные состояния, награды и сбросы проверяются как прежде.
Они ускорились с 21,00+11,63 с до 1,30+1,26 с. Три целевых теста после
оптимизации прошли за 8,81 с (14,40 с со стартом).

Окончательный полный GPU-прогон: **296 passed**, pytest 555,93 с;
полное время вместе с подготовкой **564,38 с (9:24)**. Лимит 600 с
соблюдён, проверки не удалялись. Единственное предупреждение — deprecation
в tensorflow_probability. Ruff, JavaScript parser и git diff --check проходят.

Чтобы не компилировать одинаковую текущую среду по отдельности для опыта,
разнообразных отрядов, столицы, зелий и начала боя, эти тестовые модули
используют общую session-фикстуру. Состояния JAX неизменяемы; сценарии
создаются через replace. Проверки и их утверждения не удалялись.
Все исполнения среды — JAX/CUDA через scripts/run_gpu.sh, CPU-прогонов нет.

## Скорость PPO

Две сопоставимые пары по 5 млн переходов, seed 42 и 43, GTX 1660 Ti.
250 сред, rollout 100, 4 эпохи PPO, 10 минибатчей, сети 128×128.
Замер полного learner с синхронизацией GPU. Компиляция, оценка, логирование
и сохранение отдельно; конкурирующих GPU-задач нет. Размеры входа и выхода
сохранились: 427 признаков и 80 действий.

| Seed | До, переходов/с | После, переходов/с | Изменение |
|---|---:|---:|---:|
| 42 | 322 139 | 338 238 | +5.00% |
| 43 | 317 622 | 335 927 | +5.76% |
| Сумма переходов / сумма времени | 319 865 | 337 079 | +5,38% |

Настройки PPO и версии пакетов совпадают; изменяется карта с новым правилом.
Замедления нет. Эти результаты включают изменение траекторий и доли боёв,
а не изолированную стоимость операции проверки клетки. После 5 млн:
argmax 0/1024 для обоих seed; sampled 329/1024 и 117/1024. Контрольные
модели не выдаются за решившие задачу. W&B ID: hogufa0e и a877agsa (offline).

Артефакты: results/targeted-engagement-20261008/{before,after}-{42,43}/,
comparison.json, full.log, full-optimized.log и соответствующие *-complete.json. Сохранены конфигурации,
зависимости, исходные хэши, checkpoints, итоги каждого миллиона переходов.
W&B offline: облачный проект ранее отвечал HTTP 403; опубликованных
графиков этих запусков нет. Это контрольные 5 млн, не 50 млн переходов.

## Ручная игра

Локальная страница http://127.0.0.1:8769/viewer.html отвечает GET 200;
сервер сообщает карту v22 и backend gpu. В браузере проверены проход
рядом без боя, кнопка атаки при остатке 8 очков (списаны все 8),
победа с сохранением исходной клетки и двойной щелчок по конкретному
соседнему противнику (списаны 10 очков). Ошибок JavaScript в консоли нет.

Viewer заново экспортирован из after-42: показан argmax-повтор с поражением
на шаге 1427; ещё два sampled-повтора достигают лимита 5000. Результаты
не представлены как успешное прохождение карты.

Свидетельства проверки: results/targeted-engagement-20261008/viewer-qa.json,
target-selection.png и targeted-battle.png.
