# Mirrow match

Новая тренировочная карта `mirrow_match`: 48 × 48 клеток. Написание **Mirrow match** сохранено по запросу.

## Карта и армии

- Столица агента: вход `(5, 5)`, северо-запад. По умолчанию Легионы Проклятых: два Одержимых, Герцог, Сектант.
- Столица скриптового бота: вход `(42, 42)`, юго-восток. Империя: два Скваера, Рыцарь на пегасе, Служка.
- У каждой столицы золотая шахта и источник своей маны: infernal у Легионов, life у Империи.
- Обе столицы распространяют землю. Сохранено последовательное перекрашивание: агент, затем бот; на клетке один владелец. Ресурсы зеркально расположены.
- По 19 одинаковых нейтральных отрядов около каждой столицы, с более сильными отрядами дальше от неё. Все отряды можно обойти; обязательного боя с Тиамат нет.
- Одна Тиамат в `(24, 24)`. При чётном размере сетки это одна из четырёх центральных клеток; остальные элементы зеркальны относительно центра `(23.5, 23.5)`.

Четырнадцать заданных отрядов: 3 гоблина; орк; орк впереди и 2 гоблина-лучника сзади; копейщик впереди и служка сзади; 2 ополченца; головорез и 2 разбойника; 3 скваера; оккультист; варвар; русалка; кракен; скальной гигант впереди и алхимик сзади в соседней колонке; 2 ангела; мантикора.

Пять добавленных: 2 крестьянина; 2 скелета; волк; гном-воин впереди и арбалетчик сзади; йети. Итого 38 нейтральных отрядов вокруг столиц + 1 Тиамат. Скриптовый бот — отдельная подвижная армия, не дополнительный статичный гарнизон.

Крупное существо занимает две клетки боевого построения, но остаётся одним бойцом. Одинаковые отдельные существа остаются разными бойцами.

## Победа и скриптовый бот

Цель `scripted_bot`: одна победа основного отряда агента над скриптовым ботом в тактическом бою. Засчитываются и нападение агента, и оборона от бота. Заклинания/свитки/предметы в обычном бою разрешены. Уничтожение бота заклинанием на карте, отдельным призванным отрядом или городским резервом не завершает эту цель. Зачистка нейтралов и убийство Тиамат тоже не заменяют победу над ботом.

Когда у бота нет доступной вражеской цели, он идёт к агенту и начинает обычный управляемый агентом бой. При недоступном пути он ждёт. Возвращение домой и отдых для восстановления сохранены.

На **всех картах** побеждённый бот возрождается через два завершённых хода: первый ход — ещё отсутствует; второй — появляется дома со стартовой армией; движение продолжает со следующего хода. На `city_defence_train` это сдвигает вторую атаку с хода 4 на ход 6, если первая победа произошла на ходу 2. Другие условия победы карт не меняются.

## Запуск

Команды ниже приведены из корня репозитория. Обучение при подготовке карты не запускалось.

Linux/macOS:

```sh
CAMPAIGN_OBSERVATION_VERSION=local5 python Big_map/train_campaign.py --map mirrow_match --scripted-bot --no-boss-roster
```

PowerShell:

```powershell
$env:CAMPAIGN_OBSERVATION_VERSION = "local5"
python Big_map/train_campaign.py --map mirrow_match --scripted-bot --no-boss-roster
```

`--total-steps`, `--n-envs`, `--run-id` и другие параметры остаются обычными параметрами тренера. Сохраняйте эту карту в отдельном каталоге эксперимента. Не используйте старые веса и VecNormalize как готовый результат обучения для новой задачи. Скриптовый бот и территория Империи должны быть включены; не добавляйте `--no-scripted-bot` или `--no-empire-territory` к тренировочному запуску этой карты. Явное отключение бота в API оставлено для диагностики; без него цель недостижима.

Оценка после обучения (из `Big_map`, замените `RUN_ID`):

```sh
CAMPAIGN_OBSERVATION_VERSION=local5 python bestmodeltest.py --map mirrow_match --objective scripted_bot --scripted-bot --run-id RUN_ID --episodes 20
```

Визуализация сохранённой модели с её нормализацией:

```sh
CAMPAIGN_OBSERVATION_VERSION=local5 python Big_map/visualize_campaign.py --map mirrow_match --objective scripted_bot --scripted-bot --no-boss-roster --model PATH_TO_MODEL.zip --vecnormalize PATH_TO_VECNORMALIZE.pkl
```

Для программного доступа:

```python
from campaign_env import CampaignEnv

env = CampaignEnv(
    map_name="mirrow_match",
    observation_version="local5",
    scripted_capital_bot_enabled=True,
    use_boss_starting_roster=False,
)
obs, info = env.reset(seed=42)
```
